# Discord Callback - Lifestyle Performance

Vercel serverless function die Discord OAuth2-koppeling afhandelt en automatisch de Client-rol toewijst na autorisatie.

## Environment Variables (in te vullen in Vercel dashboard)

- DISCORD_CLIENT_ID
- - DISCORD_CLIENT_SECRET
  - - DISCORD_BOT_TOKEN
    - - DISCORD_GUILD_ID
      - - DISCORD_CLIENT_ROLE_ID
       
        - ## Redirect URL in Discord Developer Portal
